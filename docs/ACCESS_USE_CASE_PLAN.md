# 原始数据访问用例规划 v0.2

状态：测试用例编写前的逻辑访问规划，**未编写可执行用例、未实现、未运行**。本轮仅整合设计。适用契约为 [DATA_SPEC.md](DATA_SPEC.md) `0.2-draft`，文档职责按 [设计维护原则](DESIGN.md#integration-policy)划分；本文件不新增规范、函数签名、HDF5 路径或性能指标。

需求理由见 [DESIGN.md](DESIGN.md)，样例、独立期望及执行状态统一在 [SPEC_TEST_PLAN.md](SPEC_TEST_PLAN.md)。下文是访问能力的规划视图，不维护第二套 U 规则或 UC 执行记录。

## 1. 规划范围与追踪

访问规划覆盖工件容器的 Scan 枚举/选择，以及 Scan 内 Frame/Stream、PA 声束、FMC 矩阵、样本选择、状态与位置绑定、分批重读及诊断消费。每个 Scan 的区域/来源/坐标映射关系及相应读取能力待 D-11 决策，不纳入已确定访问语义。第 3 节直接对应本项目 UC 回归集；生命周期、规模和可选加速沿用项目 T 追踪，不创建平行执行账本。

所有已定义的访问语义均在 DATA_SPEC 和本文件中闭合；具体请求频率、资源阈值、返回容器和缓冲契约仍属 D 项，不以外部编号或未提供的附件补充隐含要求。

## 2. 公共请求与结果的逻辑契约入口

一次逻辑请求由 Scan、Frame 选择、输出选择和样本选择构成；按需要求原始位置绑定。这是概念组成，不是正式 request 类型。

先在文件中明确选择 Scan，不默认“最新”或第一个扫描。多个 Scan 的组合消费保留各自身份、固定定义、Frame 轴及样本表示，不自动拼接、重采样或筛除旧数据。用途/区域、Scan 间来源及坐标映射的必要性、模型和访问结果待 D-11，不能先把它们规定为必读元数据；Scan 枚举接口仍见 D-10。

| 选择维度 | 公共含义 | 契约入口 |
|---|---|---|
| Scan | 文件内枚举/明确选择；区域/来源/坐标映射能力待决策 | SCAN-01、READ-01；待定 SCAN-02/D-11 |
| Frame | 连续范围、有序离散清单，多帧可分批 | REC-01、READ-02、CAP-01 |
| 波形流 | 指定流或流清单，事件与接收输出静态可追溯 | 逻辑模型、WAV-01 |
| PA 声束 | 束身份映射到正确事件/输出，关联唯一帧位置与固定几何/法则 | PA-01 |
| FMC Tx/Rx | 全矩阵、行、列、有序交叉子矩阵或显式配对 | FMC-01/02 |
| Sample | 全波形、样本范围/有序清单，或给定逐流/逐对选样；清单保序保重复 | READ-02 |
| 状态与位置 | 波形附带对应状态；绑定读带原始 Frame 位置，独立读取仍可核对来源 | STA-01、POS-01、READ-01 |

结果必须足以识别所选 Frame、流或束/Tx/Rx 轴、状态及必要固定定义来源。并不要求每个结果逐份复制定义内容；可交付可核对引用。异构返回有身份的数组集合/波形矩阵或分组结果，不能用单一 ndarray 作为全部模式的强制结果类型。

半开区间、有序清单与逐流边界语义引用 [READ-02](DATA_SPEC.md#read-02)。请求级拒绝或逐项错误、空选择表示、负索引/逆序语法均未选定，留待 D-10；本次不为测试方便提前决定。空结果不得伪装请求失败。

| 多 Scan 生命周期与恢复 | 已完成 Scan 拒绝追加，未封存文件可继续新 Scan；恢复范围逐 Scan 报告 | UC-19；T-12/T-15 |
| 单晶异构回读 | 指定 Frame/流联合读，各流保持原始 dtype、长度、符号及采样解释 | UC-01～04 |
| 单波形与批量流读取 | 有序 Frame/Stream 清单，保序保重复，状态与固定引用对应 | UC-05 |
| 独立波形/位置及绑定读取 | 原始来源可对照；未知位置编码不伪造位置，受限访问遵守 ID-02 | UC-05/16；T-06/07 |
| PA 完整帧与束集合 | 完整束集合及 `[2,0,2]` 等选择，一帧唯一 P_n，束关联 G/L | UC-06/07 |

| FMC 完整输入块 | 由 π 组矩阵，流目录乱序仍正确；拒绝覆盖缺口、别名、悬空引用及 Tx/Rx 身份冲突；同构取得 `[Frame,Tx,Rx,Sample]` | UC-09/13 |
| FMC 固定 Tx / 固定 Rx | 行列身份分别明确，结果与完整矩阵对应部分等价 | UC-10 |
| FMC 有序子矩阵 | Tx 和 Rx 清单作交叉选择，保留各轴顺序与重复项 | UC-10；空/边界变体 |
| FMC 显式收发对 | 配对清单只返回列出的对，互易对不复用，不展开笛卡尔积 | UC-11 |
| 共同样本窗口 | 按每个流 S_k 验证边界；一流越界不冒充完整成功 | UC-12 |
| 有序样本清单 | 保留样本顺序、重复项和原始样本身份；逐流检查边界，不因内部排序/去重改变交付 | UC-12；独立预期见 SPEC_TEST_PLAN |
| 逐对选样/窗口 | 每对可不同，来源和样本身份不丢失；可在已读输入块上完成 | UC-12 |
| 异构 FMC | 保留各单元 dtype/长度/采样解释；不隐式补齐或转换 | UC-13 |
| 多帧、分批、多遍 | 不同分批划分、重读及等价选择保持结果；上一次选择不污染下一次 | UC-14 |
| 缺失与无效诊断 | 区分无 payload、存在但业务无效、结构缺口及解码错误 | UC-15 |

## 4. TFM 与其他离线算法的消费边界

TFM 可消费完整输入块、Tx/Rx 子矩阵或明确收发对，并根据调用者给定的逐对选样表取样。访问层提供可追溯原始数据，不负责传播时间、声速模型、定位或重建。

- 优先规划输入块读取、块内选样及重复消费，而非“每个像素一次磁盘 I/O”。
- 稠密数值视图不代表共同物理时间轴；采样解释不同必须保留差别。
- 缺失不能作为真实零信号；业务无效的数据保留，算法处理策略由消费者明确。
- Tx/Rx 不是工件空间网格，派生图像不能替代或覆盖原始波形。
- 实时显示走采集内存；本规划面向封存文件，异常文件仅显式只读恢复。

本轮仅规划 Q 选样表的已知结果，不验证 TFM 算法或性能。

## 5. 分批和读取错误的设计边界

矩阵读取不得以全扫描驻内存为前提。按 Frame 批次或明确选择分解请求时，结果顺序、重复项、状态、位置及固定引用须与等价整体选择一致。小样例只能验证等价关系，不证明超过 RAM 的资源目标。

| 情况 | 规划中的处理 | 不允许的处理 |
|---|---|---|
| 选中流样本越界 | 明确指出越界流与范围；请求级或逐项错误形式待 D-10 | 静默截断、补零或伪装完整成功 |
| 业务无效但有 payload | 返回原始样本和状态 | 静默过滤 |
| 声明缺 payload | 明确保留缺失语义，稠密交付不能把填充值当原始数据 | 冒充完整 FMC payload |
| 必要引用/结构损坏 | 报告结构或关联错误 | 缩短正常扫描或降格为业务无效 |
| 未支持编码/filter/选择 | 报告不支持及可用受限范围 | 返回错误数值或计为 PASS |
| 解码失败 | 报告读取错误 | 转成调用者业务无效 |

具体生产批量错误容器、取消、重试、缓冲所有权与零拷贝仍属 D-02/D-05/D-10，当前不猜测默认值。
