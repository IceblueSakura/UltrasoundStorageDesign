# ADR-0007：文档结构——ADR、0.3-draft、只列未决问题

- 状态：已采纳（2026-10-24）
- 影响：全部文档

## 背景

0.2 的活动文档约 9.8 万字符，同一规则在多处重述，"零填充"出现 66 次、"poll" 86 次。改一个决定通常要同步 5–6 份文档，已经出现措辞漂移，例如 poll 的失效条件、"批次"与"调用级"。决定的理由散落在 DESIGN、DATA_SPEC 与 DECISION_DIRECTIONS 之间。

## 决定

1. 已采纳的决定写入 `docs/decisions/` 下的 ADR，一页一个；DATA_SPEC 只改规则本身，其他文档引用规则编号，不重述规则。
2. DECISION_DIRECTIONS 只保留尚未决定的问题；已决定的部分改为指向 ADR 的链接。
3. 本轮的契约变化（ADR-0001～0006）将 Spec 修订为 `0.3-draft`。草案修订之间不承诺文件兼容（DOC-01）。
4. 各文档开头只写一行状态。

## 后果

- 历史修订说明不再在正文里逐段保留，可从 ADR 与 Git 历史追溯。
- 场景审计与访问规划保留各自的职责，只更新受影响的条目。
