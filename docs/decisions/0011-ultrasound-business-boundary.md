# ADR-0011：以 UMS 已确认需求收敛超声专用 SDK 业务边界

- 状态：已采纳（2026-11-16）；部分被 [ADR-0016](0016-tiered-core-mode-schemas-and-immutable-seal.md) 调整（封存后原地替换原文件快照改为 Write-Once 不可变＋旁路派生文件，基础取值与多回波选择移出 Core 归独立可选扩展层），其余业务边界保持有效。
- 规则落点：[BUS-01](../DATA_SPEC.md#bus-01)、[RET-01](../DATA_SPEC.md#ret-01)、[REL-01](../DATA_SPEC.md#rel-01)、[SNAP-01](../DATA_SPEC.md#snap-01)、[ACCESS-01](../DATA_SPEC.md#access-01)、[MEAS-01](../DATA_SPEC.md#meas-01)、POS-01、D-01/D-09/D-11/D-13/D-16～D-18。
- 来源：`UltrasoundMicroscopeSystem` 的 `docs/02-subsystems/storage-and-catalog.md` §1–2.1（U63/U64/U69～U72）、`docs/02-subsystems/compute-and-analysis.md` §2.2/2.4，以及用户对此轮整体审阅的确认。源仓库当时为未提交工作树，不把提交版本冒充本次需求内容。

## 背景

旧草案以原始波形文件内 Core 为主要范围，将领域 schema 和派生成果后置、禁止封存后更新，尚未回答无位置记录和仅特征保留。UMS 实际需求现已明确超声数据解释、快照及基础访问责任，同时排除完整处理、标注/缺陷、点云和导出；直接沿用旧排除项将不能承接这些业务。

## 决定与理由

以超声专用规范存取作为单一产品边界，而不是继续限定为旧波形 Core，也不是扩张成完整检测成果平台。具体规则只在 DATA_SPEC 维护：

- 模式 schema、必要关系、曲面采用几何服务于已有数据解释，不服务于复现完整扫描工程。
- 三种保留模式、无位置记录、位置异常保全波形和如实表达缺口是合法业务，不用伪波形或零坐标绕过。
- C 扫快照可在重开后新增/指定替换，但原始事实不变、失败不破坏原成果；不由此开放原始续写或通用更新。
- 基础取值和子集访问有明确范围，不承载复杂处理、转换、点云、标注/缺陷成果或额外导出。
- 布局确定存取优化重点，不限制其它布局；旧 Core I/O／纯选择层不等同于业务顶层代表／底层来源访问。

## 替代范围与保留事项

替代旧“产品首版仅 Core、领域 schema 全部后置、不做任何门取值、封存后整文件禁止更新”的范围。修订原始位置必需且异常接收未定的业务规则。ADR-0003 的单一波形有效位保留为局部规则，不替代保留/缺口/位置/特征状态；ADR-0006 保留原始 I/O 工程划分，但不再限定整个产品访问范围或优化优先级。

未冲突的 HDF5、流组/Frame、并发、所有权及失败保护等决定在原适用范围内保留；本次不把它们重新批准为新增内容的唯一模型。混合扫描范围、必要关系模型、代表规则、取值定义及快照分组继续待定，不推定共享 Frame/位置，不冻结 API、物理格式或首发范围。

## 后果与验证边界

SDK 设计细节由本仓库权威维护，UMS 保留业务需求及接入约束，避免两份规范。旧实验与 UC/T 只保留原证据及适用范围，不能证明本次新业务已经实现或验收。按用户要求，本次仅更新设计规划，不修改或执行 SDK 既往代码、实验或测试。
