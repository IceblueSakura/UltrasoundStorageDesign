# ADR-0012：基础访问的已定输出与算法暂缓边界

- 状态：已采纳（2026-11-16），部分被 [ADR-0014](0014-configurable-selection-and-snapshot-source.md) 替代；下文“最新有效／到达先后”仅保留为原决定背景，不再作为当前预选方向。候选有效性及前沿输出边界仍有效。
- 规则落点：[ACCESS-01](../DATA_SPEC.md#access-01)、[MEAS-01](../DATA_SPEC.md#meas-01)、D-17/D-18。
- 来源：用户在 ADR-0011 后的交互确认；本次只确认业务边界，不讨论实现。

## 决定与理由

代表波形只在已选定扫描、通道/声束及声路的同类观测中，从目标位置的有效重复测量选择；无有效候选时不返回无效波形兜底。有效性沿用已记录状态，不增加 SDK 质量判定。

用户希望近似取得最新有效测量，同时指出 SDK 无法确认准确采集时间。以到达先后估测保留为方向，但采集侧接收或交付给 SDK 的到达环节暂不选择，不把近似描述为真实采集时刻或已冻结顺序。

前沿取值需要同一前沿点的位置/时间与幅值。用户将后续统一提供算法参考，本轮不选择首次越阈、回波峰值等判据，也不先行确定边界处理或实现方案。

## 后果

更新已定候选范围、有效性筛选及输出要求，D-17/D-18 仍部分开放。后续依据用户参考细化，不通过测试断言或默认实现提前作答；参考内容也不自动扩大 SDK 已确认的单一职责。未修改或运行代码、实验与测试。
