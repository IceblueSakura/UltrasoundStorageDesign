# ADR-0013：确认区域关系、重点访问及子集范围

- 状态：已采纳业务范围（2026-11-16）；[ADR-0016](0016-tiered-core-mode-schemas-and-immutable-seal.md) 确立区域为文件内独立实体（D-11）并重申跨文件复检归 D-19。
- 补充：[ADR-0015](0015-cross-system-data-delivery.md) 把原扫描位于其他文件时的复检关系留待 D-19。
- 规则落点：[REL-01](../DATA_SPEC.md#rel-01)、[SCAN-02](../DATA_SPEC.md#scan-02)、[ACCESS-01](../DATA_SPEC.md#access-01)、D-03/D-11/D-17。
- 来源：用户在 ADR-0012 后继续交互确认，不涉及实现设计。

## 决定与理由

扫描须关联目标区域，复检或局部重扫须能指向原扫描的具体区域；新旧结果保持独立。用户暂不确定区域信息的具体范围，不能将区域关系直接扩成几何表达或计算能力。对象归属未被选为本轮必需关系，不等于禁止应用保存该信息或删除旧 Core 工件容器模型。

五类已有数据访问均是重点：C 扫快照浏览、选点取 A 波形、区域批量读取/基础取值、B/D/S 等布局批量读取，以及遍历整次扫描。不强行排序，不据此承诺同等速度或选定物理布局。

规范子集须能按扫描、空间区域、通道/声束/收发组合及波形样本窗口选择，并保留必要解释与来源。采集记录区间未被追加为本轮必需选择维度，不据此删除旧 Core 的记录索引访问。

## 后果与未决项

待定项由“是否需要这些关系和选择范围”转为具体业务含义及后续合同；不预设区域形状、坐标表示、关系基数、选择语法或文件组织。算法仍等待用户后续统一提供参考，未修改或运行代码、实验与测试。
